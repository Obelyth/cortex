# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or issue, please report it by emailing our support team at support@obelyth.cloud.

Please include as much detail as possible, including steps to reproduce, affected versions, and potential impact. Do not open a public issue for security vulnerabilities.

You can expect an acknowledgement within 48 hours, and we will keep you informed as we investigate and resolve the report.
